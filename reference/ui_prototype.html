Run with Gemini by copy and paste

  1. Copy the prompt package below. Put the part under "System instruction" into Gemini's system instruction, and the part under "User message" as the message.
  2. Set the response type to JSON and the temperature to about 0.2.
  3. Paste Gemini's JSON answer into the box and load it.
